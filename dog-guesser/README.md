# 🐶 Dog Guesser

Devine la race du chien ! 10 manches, 4 propositions, bonus de rapidité et de série.
Les records sont sauvegardés dans `scores.json` et mis à jour en direct pour tous les joueurs connectés.

## Installation
```
pip install -r requirements.txt
```

## Lancement
```
python main.py
```
Le jeu s'ouvre sur http://127.0.0.1:8080 (ouvrir plusieurs onglets pour voir les records en temps réel).

## Partie 0

Le dossier `partie0` contient la prise en main (requêtes HTTP, client et serveur WebSocket) : `pip install -r partie0/requirements.txt`.
