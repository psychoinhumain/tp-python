# TP Python

Travaux pratiques de Python sur la communication à travers le réseau.

## Projets

- `dog-guesser` : jeu de devinette de races de chiens, avec records en temps réel. Le dossier `partie0` contient la prise en main, avec les requêtes HTTP et le client et serveur WebSocket.
- `tableau-interactif` : tableau de dessin partagé en temps réel, avec un serveur HTTP et WebSocket, une page web et un client en ligne de commande.

## Lancement

Chaque projet possède son propre README avec l'installation et le lancement. Il faut d'abord se placer dans le dossier du projet, par exemple :

```
cd dog-guesser
pip install -r requirements.txt
python main.py
```
